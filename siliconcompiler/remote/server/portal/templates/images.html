Registering an image chooses what code executes on the cluster.

Higher stakes than any read permission: a permission decides who may see something, this decides what runs as the account a job maps to. The tag is pinned to a digest the moment you register it, so rebuilding that tag later does not change what already-accepted jobs run — that takes registering it again. Every image here has a person on it.
