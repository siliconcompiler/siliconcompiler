The request body’s Content-Type is not one this endpoint accepts.

What to do

  1. Send application/json to the JSON endpoints.

An untyped answer is expected here. This refusal is often produced below the request handler — by routing, the framework or a proxy — and then it arrives as the web server’s own page, not as application/problem+json, and has no type at all. Treat a non-problem+json 415 exactly as you would this type.
