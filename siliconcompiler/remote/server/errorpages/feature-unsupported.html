feature-unsupported

This deployment does not support that

501 Not Implemented https://siliconcompiler.com/server-errors/feature-unsupported

This deployment does not offer the capability you asked for. It is permanent — a statement about the deployment, not its current state.

What to do

  1. Read feature.
  2. Check GET /v1’s features before calling: a capability is only offered where it is listed.
  3. Do the thing another way — for logs.stream.job, follow each running node instead; for logs.stream, read the archived log once the node finishes.

The body

{
  "type":     "https://siliconcompiler.com/server-errors/feature-unsupported",
  "title":    "This deployment does not support that",
  "status":   501,
  "detail":   "...",
  "instance": "/v1/jobs/01J9...",
  "feature":  "logs.stream",  // REQUIRED on this type
  "trace_id": "4bf92f3577b34da6a3ce929d0e0e4736"
}
Member
featureREQUIRED The capability: logs, logs.stream, logs.stream.job, projects, device_grant or python.env. Where several are missing, the broadest is named.
trace_idoptional The same W3C trace id as the response header. Quote it in a support request.

detail is prose and may be reworded at any time. Branch on type, and read the members above for the specifics — never parse detail.

Where it comes from

GET /v1/jobs/{id}/logs logs, logs.stream, logs.stream.job.
POST /v1/auth/device device_grant.
POST /v1/jobs projects, or the first string in descriptor.needs this deployment does not offer.
POST /v1/jobs/{id}/submit python.env, for a job carrying a Python environment file it did not declare.

Getting help with your specific failure

Two members of the body identify your exact request. Quote both when you escalate — with them, whoever helps you finds the one request instead of searching a five-minute window.

  • trace_id — the correlation id. The same value is on the response as a header, so it is in your logs even if the body is not.
  • instance — the request this happened to.

This page documents the error type. It is the same page for everyone who hits it and it cannot see your response — trace_id is what connects the two.

What this is not

not-ready is transient and should be retried.

Normative definition: the error type registry in the SiliconCompiler v1 API contract. This page is a rendering of it — where the two disagree, the registry is right.
